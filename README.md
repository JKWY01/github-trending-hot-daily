# GitHub Hot Daily · 每日 GitHub 爆火开源项目火线榜

> Daily snapshot of the hottest open-source repositories on GitHub, ranked by star momentum, growth rate and rising velocity.

## What you get here

- **`archive/YYYY-MM/YYYY-MM-DD.md`** — full daily snapshot, committed automatically every day after the ranking pipeline publishes (34 boards, star momentum, growth rate, dark horses).
- **`README.md`** — always reflects the latest published day: Overall Top 50, Today's Ignition Top 30, Dark Horses Top 20.
- Every entry links back to its live page on [git.zoyku.com](https://git.zoyku.com) with per-repo rank history, 7/30-day star charts and comparison radar.

## Why this repo exists

Rankings decay fast, but the data behind them is history. This archive preserves the daily "who was hot and when" record — useful for spotting long-term trends, researching project lifecycles, and discovering rising projects before they hit the mainstream.

All data is captured from public GitHub activity and published with honest methodology (no star inflation, no paid placement). See the [methodology guide](https://git.zoyku.com/zh/guide).
